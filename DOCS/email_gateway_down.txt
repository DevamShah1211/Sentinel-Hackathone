Testing the gateway's TCP ports directly:

    Port 8554 (RTSP)    Connection refused

    Port 443 (HTTPS)    Open

"Connection refused" is a specific result. It means the server actively rejected the connection rather than dropping it, which indicates no service is listening on that port. A firewall block would time out silently, and a credential problem would require the connection to succeed first in order to return 401. Ports 443 and 80 on the same host accept connections normally, so the host itself is up and reachable.
